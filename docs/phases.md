# แผนพัฒนาเว็บไซต์ CHNS ทีละเฟส

แผนนี้ปรับลำดับจากเอกสารต้นทางให้เข้ากับ repository ที่เริ่มจาก Next.js starter และใช้ [เว็บไซต์ตัวอย่าง](reference-sites.md) เป็นแนวทางด้านประสบการณ์ผู้ใช้ สถานะจริงของแต่ละเฟสอยู่ใน [progress.md](progress.md)

| เฟส | ผลลัพธ์ที่ต้องได้ | เงื่อนไขก่อนปิดเฟส |
| --- | --- | --- |
| 1. ฐานเว็บและความถูกต้องของข้อมูล | Design foundation, หน้าแรก/เกี่ยวกับ/ฝ่ายงาน/ร่วมสนับสนุนแบบข้อมูลที่ตรวจได้, navigation, responsive, metadata, บันทึกช่องว่างข้อมูล | ไม่มีข้อมูลแต่งขึ้นหรือลิงก์เสีย; lint/build ผ่าน; ยังไม่เปิดธุรกรรม |
| 2. โครงเนื้อหาและหลังบ้าน | ฐานข้อมูล, auth, RBAC, admin สำหรับข่าว โครงการ รายงาน สื่อ และ featured; หน้า public อ่านเฉพาะ published | ทดสอบ role, draft visibility, audit, backup และ workflow อนุมัติ |
| 3. เครือข่ายและความโปร่งใส | ศูนย์ประสานงาน องค์กรสมาชิก รายงาน และตัวเลขผลลัพธ์พร้อมที่มา | เจ้าของข้อมูลอนุมัติรายการและสิทธิ์ภาพ/ไฟล์ |
| 4. การมีส่วนร่วม (พักงานสมัครสมาชิก/บริจาค) | ฟอร์มสมัครสมาชิกองค์กรและระบบบริจาคเก็บเป็นแนวคิดระยะหลัง; งาน analytics และ SEO/redirect ประเมินแยกเมื่อเว็บหลักพร้อม | รอคำสั่งให้เริ่มงานสมัครสมาชิก/บริจาคและขั้นตอนจริงจากองค์กร |
| 5. ส่วนขยาย (พักงานภาษาอังกฤษ) | ภาษาอังกฤษ แผนที่โต้ตอบ การค้นหาขั้นสูง และ dashboard เป็นงานระยะหลัง | รอคำสั่งให้เริ่มและข้อมูลที่อนุมัติ |

เริ่มและปิดทีละเฟส; ความต้องการที่ยังขาดข้อมูลให้บันทึกไว้ใน [decisions.md](decisions.md) โดยไม่ใช้ข้อมูลตัวอย่างแทนข้อมูลจริง

**ขอบเขตปัจจุบัน:** ทำเฟส 2 ต่อที่ระบบคอนเทนต์/หลังบ้าน แล้วจึงพิจารณาข้อมูลเครือข่ายในเฟส 3 งานสมัครสมาชิก บริจาค และภาษาอังกฤษพักไว้ตามคำขอผู้ใช้ ไม่ใช่งานค้างที่ต้องทำเพื่อปิดเฟส 2 และไม่เริ่มพัฒนาเองในรอบนี้ หน้า preview ที่มีอยู่คงไว้เพื่อดูโครงเว็บ โดยไม่เปิดฟอร์มหรือธุรกรรมจริง

## รอบโครงหน้าสาธารณะ (25 กันยายน 2569)

ตามคำขอให้วางทุกหน้าก่อนเชื่อมระบบ ได้เพิ่มหน้า preview ของทุกหมวดหลักใน sitemap และภาพจำลองสำหรับทดสอบ layout รอบแรกเป็น **งานออกแบบหน้าจอ** ไม่ถือว่าเฟส 2–5 เสร็จ ต่อมาจึงเริ่มเชื่อม CMS ตามบันทึกด้านล่าง

อัปเดต: เฟส 2 มีโมดูล Hero, ข่าว/บทความ, โครงการ, รายงาน PDF และการเลือกเนื้อหาเด่นหน้าแรกที่ใช้ Supabase แล้ว ทุกโมดูลตรวจสิทธิ์ก่อนแก้ข้อมูล หน้าเว็บอ่านเฉพาะรายการที่เผยแพร่ รายละเอียดอยู่ใน [hero-carousel-admin.md](hero-carousel-admin.md), [article-admin.md](article-admin.md), [project-admin.md](project-admin.md), [report-admin.md](report-admin.md) และ [homepage-features.md](homepage-features.md). คลังสื่อร่วม, workflow หลาย role และ revision รออนุมัติยังไม่เสร็จ จึงยังไม่ปิดเฟส 2

ผู้ใช้เลือก **Supabase** และเชื่อม Auth/ข้อมูล/ไฟล์กับโปรเจกต์แล้ว รายละเอียดใน [supabase-setup.md](supabase-setup.md)
