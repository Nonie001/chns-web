# รายงานและ PDF: โมดูลหลังบ้านเฟส 2

สถานะ: ใช้งานในเครื่องได้สำหรับผู้ดูแล `admin`; รายงานจริงต้องให้เจ้าของข้อมูลตรวจและอนุมัติก่อนเผยแพร่

## การใช้งาน

1. เข้าสู่ระบบที่ `/admin/login` แล้วเปิด `/admin/reports`
2. เพิ่มรายงานด้วย slug, ปี, ชื่อ, ประเภท, เจ้าของข้อมูล/แหล่งที่มา และคำอธิบาย บันทึกร่างได้โดยยังไม่แนบไฟล์
3. แนบ PDF ไม่เกิน 15 MB และยืนยันสิทธิ์เผยแพร่ไฟล์ก่อนบันทึก ระบบตรวจ MIME หรือชื่อนามสกุล `.pdf` เมื่อเบราว์เซอร์ไม่ระบุ MIME พร้อมตรวจลายเซ็น `%PDF-` ของไฟล์
4. กดเผยแพร่จากหน้ารายการได้เมื่อมี PDF, แหล่งข้อมูล และการยืนยันสิทธิ์ รายงานจะขึ้นที่ `/reports`, `/reports/[slug]` และผลค้นหา
5. ปิดเผยแพร่หรือเก็บถาวรจากหน้ารายการได้ทันที ลิงก์หน้ารายงานและ PDF จะตอบ 404 สำหรับผู้ไม่ได้ล็อกอิน

## ข้อมูลและสิทธิ์

- `reports` เก็บเนื้อหา สถานะ และชื่อไฟล์สุ่ม; `report_audit` เก็บผู้ทำ เวลา และค่าก่อน/หลังเมื่อสร้าง แก้ หรือเปลี่ยนสถานะ
- หน้า public อ่านเฉพาะ `published` ที่มีไฟล์ PDF; หน้า admin, Server Actions และไฟล์ร่างตรวจ session กับ role `admin` ที่ server
- ไฟล์อยู่ใน private Supabase Storage ไม่อยู่ใน `public/`; route `/api/report-files/[key]` ตอบเป็น attachment พร้อม `nosniff`, `sandbox` และ `no-store`
- การแก้รายงานที่เผยแพร่มีผลทันทีและบันทึก audit; ระบบยังไม่มี revision ที่รอตรวจโดยไม่เปลี่ยนหน้าสาธารณะ
- รายงานตัวอย่าง 3 รายการอยู่ใน Supabase เป็น draft สำหรับพรีวิวหลังบ้านและไม่ปรากฏบนหน้าสาธารณะ

## สำรองข้อมูลและข้อจำกัด

`npm run backup:local` ใช้กับข้อมูล SQLite เดิมเท่านั้น ข้อมูลปัจจุบันใน Supabase ต้องมีแผนสำรองและทดสอบกู้คืน ไฟล์ที่ถูกแทนหรือลบจากรายการอาจยังค้างใน Storage; ขั้นตอนเก็บกวาดไฟล์ต้องออกแบบพร้อมนโยบาย retention

การตรวจ MIME/ลายเซ็น/ขนาดเป็นการกรองเบื้องต้น ยังไม่มีการสแกนมัลแวร์หรือ workflow อนุมัติหลาย role จึงยังไม่ถือว่าพร้อมเปิดรับรายงานภายนอกโดยตรง

## การตรวจรอบนี้

- ทดสอบบนฐานข้อมูลชั่วคราว: สร้างร่างผ่านฟอร์มจริงแล้วหน้ารายงานตอบ 404; กดเผยแพร่โดยไม่มี PDF ถูกปฏิเสธ
- แนบ PDF ทดสอบและยืนยันสิทธิ์: PDF ร่างตอบ 404 ต่อผู้ไม่ล็อกอิน; หลังเผยแพร่หน้ารวม/รายละเอียด/ค้นหาแสดงรายงานและ PDF ตอบ 200
- ปิดเผยแพร่แล้วหน้ารายละเอียดและ PDF ตอบ 404; สำรองข้อมูลแล้ว `PRAGMA integrity_check` เป็น `ok` และ PDF อยู่ในชุดสำรอง
