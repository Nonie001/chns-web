# วิเคราะห์เว็บไซต์ตัวอย่างสำหรับ CHNS

ตรวจเมื่อ 25 กันยายน 2569 จากหน้าแรกของ [Islamic Relief Worldwide](https://islamic-relief.org/) และ [Muslim Hands UK](https://muslimhands.org.uk/) พร้อมดูหน้าจอจริงบน desktop ข้อสรุปด้านล่างเป็นการนำหลักการจัดลำดับข้อมูลมาใช้ ไม่ใช่การคัดลอกภาพ สี ข้อความ หรือรูปแบบเฉพาะขององค์กรอื่น

| ประเด็น | Islamic Relief Worldwide | Muslim Hands UK | แนวทางสำหรับ CHNS |
| --- | --- | --- | --- |
| ส่วนบนของหน้า | ภาพภารกิจขนาดใหญ่ เมนูหลักสั้น และปุ่ม Donate เด่น | ภาพภารกิจเต็มพื้นที่ เมนูสั้นและปุ่ม Donate เด่น | ใช้ชื่อองค์กรและภารกิจที่อ่านง่ายใน 1 หน้าจอ พร้อม CTA “ร่วมสนับสนุน” ที่นำไปยังข้อมูลที่ตรวจแล้ว |
| เส้นทางผู้ใช้ | แยก Giving, Our work, About us, Resources; มี Current campaigns | แยก Giving, Our work, About us; มีแคมเปญและวิธีช่วยเหลือ | แยก “งานของเรา” จาก “ร่วมสนับสนุน”; ไม่รวมฝ่ายงานทั้งหมดเป็นเมนูยาว |
| ความน่าเชื่อถือ | มี Our Impact, ข่าว, annual report และนโยบาย | มี Our promise, ผลลัพธ์ และหน้า how money is spent | พื้นที่ผลลัพธ์ต้องมีปี/ที่มา/หลักฐานจริง; โครงการเชื่อมรายงานและข่าวได้ |
| การบริจาค | Quick donate และตัวเลือกจำนวนเงิน | CTA ไปหน้า appeal และเส้นทาง Zakat เฉพาะ | ยังไม่ทำฟอร์มการเงินจน CHNS ยืนยันบัญชี วิธีตรวจยอด และใบเสร็จ |
| เนื้อหาต่อเนื่อง | ข่าว/อัปเดตและรายงาน | เรื่องงาน ภาคี และช่องทางมีส่วนร่วม | ควรให้หลังบ้านจัดข่าว โครงการ รายงาน และส่วน featured หน้าแรก |

## สิ่งที่จะใช้ในเฟสแรก

- โครงหน้าแรกแบบ editorial: ภารกิจองค์กร → งานของเรา → หลักความโปร่งใส → การมีส่วนร่วม
- Header สั้น อ่านง่ายบนมือถือ และ CTA คงที่ในส่วนบน
- ระบบสีและตัวอักษรของ CHNS เอง โดยใช้ text mark ชั่วคราวจนได้รับโลโก้ทางการ
- ใช้ภาพเชิงนามธรรมที่สร้างด้วย CSS ในช่วงต้น เพราะยังไม่มีการยืนยันสิทธิ์ภาพภารกิจจากเอกสาร

## สิ่งที่ยังไม่ยืมมาใช้

- แถบกรอกจำนวนเงินบริจาคและยอดคืบหน้า เพราะยังไม่มีระบบรับเงิน/ตัวเลขที่ตรวจแล้ว
- ตัวเลขผลกระทบ ตัวอย่างโครงการ และเรื่องราวบุคคลจากองค์กรตัวอย่าง
- ภาพภารกิจของเว็บไซต์ตัวอย่างหรือภาพในเอกสารที่ยังไม่ยืนยันสิทธิ์

ข้อมูลอ้างอิง: [หน้าแรก Islamic Relief](https://islamic-relief.org/), [หน้าแรก Muslim Hands](https://muslimhands.org.uk/)
