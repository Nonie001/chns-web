# ทิศทางออกแบบเว็บไซต์ CHNS ใหม่ทั้งระบบ

สถานะ: ปรับรอบสองตาม UNHCR Thailand แล้ว โดยใช้พื้นขาวกับเขียวเป็นหลัก ภาพภาคสนามจริงยังรอไฟล์และรายการที่อนุมัติ

## ทิศทางล่าสุด: เว็บไซต์องค์กรทางการ

- ใช้ Header พื้นขาวแถวเดียว: โลโก้กับคำว่า CHNS ทางซ้าย เมนูหลักและปุ่มร่วมสนับสนุนในแถวเดียวกัน เมนูย่อยเปิดเมื่อชี้เมาส์ตามพฤติกรรมที่กำหนดไว้
- ให้ภาพกิจกรรมเป็นจุดนำสายตา พร้อมหัวข้อสั้น อ่านชัด และทางไปสำรวจภารกิจ; ภาพหน้าแรกปัจจุบันเป็นภาพจำลอง มีคำกำกับ ไม่ใช่หลักฐานกิจกรรมจริงของ CHNS
- ใช้พื้นขาวและเขียวอ่อนสลับช่วงเนื้อหา สีเขียวเข้มใช้เฉพาะส่วนที่ต้องเน้น ลดสีทองและพื้นทึบขนาดใหญ่
- เมื่อ CHNS ส่งภาพที่มีสิทธิ์เผยแพร่ ให้แทนภาพจำลองใน Hero และส่วนวิธีทำงานก่อนขยายไปหน้าโครงการและข่าว โดยใส่วันที่ สถานที่ และเครดิตภาพตามข้อมูลที่อนุมัติ

ตรวจวันที่ 26 กันยายน 2569 จากเว็บ CHNS ที่ `localhost:3002`, โค้ดหน้าสาธารณะ และเว็บไซต์ตัวอย่างที่เจ้าของโครงการส่งมา เอกสารนี้เป็นแนวทางออกแบบ ยังไม่ใช่เนื้อหาที่อนุมัติให้เผยแพร่

## ข้อวินิจฉัย

1. ภาพหน้าแรกหลายภาพเป็นภาพเชิงสัญลักษณ์ของการประสานงาน ไม่บอกว่า CHNS ทำอะไร ในพื้นที่ไหน หรือช่วยใคร จึงสร้างความรู้สึกร่วมได้จำกัด
2. Hero ปัจจุบันสื่อสารพันธกิจระดับกว้าง แต่ไม่มีภารกิจเด่นหรือเรื่องจริงให้ติดตาม ส่วนโครงการและข่าวที่อยู่ใน Supabase ยังเป็น draft จึงไม่ขึ้นหน้าเว็บจริง
3. หน้าในอย่างน้อย 16 หน้าใช้ `PageHero` รูปแบบเดียวกัน: พื้นสีเข้ม หัวข้อใหญ่ และคำอธิบายสั้น ทำให้ทุกหน้ามีจังหวะคล้ายกัน
4. ภาพและข้อความหลักซ้ำแนวคิด “เครือข่าย/ความร่วมมือ/มนุษยธรรม” หลายช่วง ขณะที่หน้ารวมฝ่ายเป็นรายชื่อ 8 กล่อง และภาคี 47 โลโก้กินพื้นที่ยาวโดยไม่มีเรื่องของความร่วมมือประกอบ
5. ระบบสีและตัวอักษรสอดคล้องกันแล้ว แต่ layout ยังใช้หัวข้อ–ย่อหน้า–การ์ดที่ใกล้เคียงกันมาก ขาดภาพนำ สัดส่วนที่หลากหลาย และลำดับความสำคัญของเรื่อง

| [Islamic Relief](https://islamic-relief.org/) และ [Muslim Hands](https://muslimhands.org.uk/) | แยกภารกิจเร่งด่วนจากงานระยะยาว ให้ผู้ใช้รู้ว่าจะช่วยเรื่องใด และเชื่อมผลลัพธ์กับรายงาน |

นำหลักการเล่าเรื่องและโครงสร้างการใช้งานมาปรับใช้ ไม่คัดลอกภาพ สี ข้อความ หรือ layout เฉพาะขององค์กรอื่น

## แนวทางสร้างตัวตน CHNS

**แกนภาพ:** “เครือข่ายที่ลงมือทำจริง” ใช้ภาพคนทำงาน พื้นที่ปฏิบัติการ การส่งต่อความช่วยเหลือ และเครือข่ายในประเทศไทยเป็นหลัก ภาพต้องมีสิทธิ์เผยแพร่ คำบรรยาย สถานที่/ช่วงเวลา และเครดิตเมื่อจำเป็น ภาพจำลองใช้เฉพาะพรีวิวหลังบ้านและระบุให้ชัด

**แกนเนื้อหา:** ทุกส่วนตอบหนึ่งในสี่คำถาม: ตอนนี้เกิดอะไรขึ้น, CHNS ทำอะไร, มีหลักฐานผลอย่างไร, ผู้เข้าชมร่วมได้ทางไหน ข้อความหัวเรื่องต้องเฉพาะเจาะจงกว่าคำระดับนามธรรม เช่นชื่อโครงการหรือพื้นที่ที่ผ่านการยืนยัน

**ภาษาภาพ:** ใช้เขียวจากโลโก้เป็นสีหลัก ร่วมกับพื้นกระดาษอุ่นและสีเน้นเพียงหนึ่งสี; ใช้เส้นโค้ง/เส้นเชื่อมจากแนวคิดโลกและเครือข่ายอย่างประหยัด จัดวางภาพใหญ่สลับภาพเล็ก ตัวพาดหัวมีขนาดหลากหลาย ลดการ์ดกรอบเหมือนกันทั้งหน้า และใช้ motion เฉพาะเพื่อบอกสถานะหรือพาอ่าน

**หลักความน่าเชื่อถือ:** ตัวเลขทุกตัวมีช่วงเวลาและแหล่งที่มา โครงการเชื่อมข่าวภาคสนาม รายงาน และหลักฐานที่เผยแพร่แล้ว ไม่สร้างแถบยอดระดมทุนหรือผลลัพธ์สมมติ

## รูปแบบหน้าแรกที่เสนอ

1. **Hero ภารกิจเด่น:** ภาพภาคสนามจริงหรือภาพแคมเปญที่ได้รับอนุมัติ หัวเรื่องเฉพาะหนึ่งเรื่อง CTA ไปโครงการ และลิงก์รองไปทำความรู้จัก CHNS หากยังไม่มีภารกิจที่เผยแพร่ ใช้ข้อความองค์กรพร้อมภาพจริงที่ได้รับสิทธิ์
2. **ภารกิจที่กำลังขับเคลื่อน:** การ์ด 1 ใหญ่ + 2 เล็ก แสดงพื้นที่ เป้าหมาย สถานะ และฝ่ายรับผิดชอบ เฉพาะโครงการ published
3. **CHNS ทำงานอย่างไร:** แผนภาพ/ภาพชุดจากการรับเรื่อง ประสานงาน ลงพื้นที่ ติดตามผล พร้อมลิงก์ไปฝ่ายที่เกี่ยวข้อง
4. **ผลลัพธ์ที่ตรวจสอบได้:** ตัวเลขสั้น ๆ เฉพาะเมื่อมีแหล่งอ้างอิง มิฉะนั้นใช้กรณีศึกษาและรายงานที่เผยแพร่
5. **เรื่องจากพื้นที่:** ภาพใหญ่หนึ่งเรื่อง + ข่าวล่าสุดขนาดย่อม พร้อมวันที่ สถานที่ และเครดิตภาพ
6. **เครือข่าย:** เลือกภาคีเด่นจำนวนพอดีหนึ่งจอและชวนไปดูหน้าองค์กรสมาชิกทั้งหมด แทนการแสดงโลโก้ 47 รายการบนหน้าแรก
7. **รายงานและการมีส่วนร่วม:** รายงานล่าสุดที่มีจริง ตามด้วย CTA แยก “ร่วมสนับสนุน” และ “สมัครสมาชิกองค์กร”

## Template ของหน้าอื่น

| กลุ่มหน้า | ทิศทาง |
| --- | --- |
| เกี่ยวกับเรา | หน้าเล่าเรื่ององค์กรด้วยภาพจริง ไทม์ไลน์ บทบาท เครือข่าย และโครงสร้างบริหาร; ไม่เริ่มทุกหน้าย่อยด้วย Hero สีเข้มเหมือนกัน |
| ฝ่ายงาน 8 ฝ่าย | แต่ละฝ่ายมีภาพ/ภารกิจเฉพาะ สิ่งที่รับผิดชอบ พื้นที่ โครงการ ข่าว และช่องทางติดต่อที่รับรองแล้ว |
| โครงการ | หน้ารวมแบบภาพนำพร้อมตัวกรองประเภท/พื้นที่/สถานะ; หน้ารายละเอียดมีปัญหา วิธีทำ ความคืบหน้า ภาพภาคสนาม ผล และรายงานที่เกี่ยวข้อง |
| ข่าว/บทความ | จัดแบบหน้าบรรณาธิการ: เรื่องนำใหญ่ ข่าวสั้นเป็นลำดับ หมวด วันที่ ภาพ และหน้าบทความที่อ่านยาวได้ดี |
| ศูนย์/ภาคี | Directory ค้นหาและกรองพื้นที่; หน้าแรกโชว์เพียงตัวอย่างเครือข่าย ไม่ใช้กำแพงโลโก้เป็นเนื้อหาหลัก |
| ร่วมกับเรา | แยกเส้นทางผู้สนับสนุนกับองค์กรสมาชิกอย่างชัดเจน; ขั้นตอนและเงื่อนไขต้องผ่านการรับรองก่อนเปิดรับจริง |
| รายงาน | ใช้ปกเอกสาร สรุปเรื่องสำคัญ ปี และไฟล์ดาวน์โหลดที่ published เชื่อมกลับโครงการที่เกี่ยวข้อง |

## ลำดับทำงาน

1. สร้างชุดภาพและข้อมูลต้นทาง: ภาพจริงที่มีสิทธิ์ใช้ 10–15 ภาพ, ภารกิจจริงอย่างน้อย 2–3 เรื่อง, ข่าว/รายงานที่อนุมัติ และข้อมูลติดต่อ/ผลลัพธ์ที่ตรวจแล้ว
2. ออกแบบหน้าแรกใหม่เป็นต้นแบบสำหรับ desktop/mobile พร้อม token สี ตัวอักษร ระยะ และองค์ประกอบภาพ ใช้ข้อมูลจริงเท่าที่มี; ส่วนที่ยังไม่มีข้อมูลให้แสดงโครงอย่างตรงไปตรงมา
3. ขยาย design system ไปหน้ารวมและรายละเอียดของโครงการ ข่าว ฝ่ายงาน แล้วจึงไปเกี่ยวกับเรา ศูนย์ ภาคี รายงาน และร่วมกับเรา
4. ตรวจการอ่านบนมือถือ ความคมของภาพ คอนทราสต์ ความเร็วโหลด ความสม่ำเสมอของเนื้อหา และเส้นทางจากหน้าแรกถึงรายละเอียดภายใน 2–3 คลิก

การเปลี่ยนโครงนำเสนอไม่จำเป็นต้องเปลี่ยน Supabase หรือ URL ที่ใช้อยู่ ข้อมูล draft ยังอยู่หลังบ้านจนได้รับอนุมัติและเผยแพร่
