# ตรวจความครบถ้วนเทียบ CHNS Revision Brief 01

ตรวจวันที่ 26 กันยายน 2569 จากไฟล์ข้อความที่ผู้ใช้ส่ง, route/component/model ใน repository และการอ่าน Supabase ด้วย anonymous key แบบอ่านอย่างเดียว **ไม่ได้เปิดหรือตรวจลิงก์ Google Drive** ตามคำขอ การมี URL หรือแบบฟอร์มตัวอย่างในเอกสารไม่เท่ากับเนื้อหาที่อนุมัติให้เผยแพร่

**ข้อสรุป:** โครงเมนูและหน้าเว็บหลักมีเกือบครบ แต่เนื้อหาทางการและเส้นทางใช้งานจริงยังไม่ครบ โดยเฉพาะประวัติ/โครงสร้าง/ฝ่ายงาน/ศูนย์, โครงการและข่าวที่เผยแพร่, การติดต่อ, การสมัครสมาชิก และการสนับสนุนผ่านเว็บไซต์

## ความคืบหน้าหลังการตรวจ (26 กันยายน 2569)

ผู้ใช้อนุมัติข้อความในเอกสารให้เผยแพร่ และเลือกให้ส่วนร่วมสนับสนุนแสดงโครงการ/ขั้นตอนโดยยังไม่รับเงิน ตารางด้านล่างเป็นผลตรวจ **ก่อน** การลงมือรอบนี้; งานที่ปิดช่องว่างแล้วมีดังนี้:

- เติมประวัติ (อ้างปีภาษาไทย), วิสัยทัศน์ พันธกิจ วัตถุประสงค์ ยุทธศาสตร์ บทบาทฝ่ายงานที่เอกสารมี, ศูนย์ภูมิภาค 11 รายการ, ที่อยู่ โทรศัพท์ อีเมล เวลาทำการ แผนที่ และ social
- เติมคำอธิบายฝ่ายงานบนหน้ารวม/รายละเอียด, breadcrumb, share, ตัวกรองโครงการ ข่าวและรายงาน, ค้นหาองค์กรสมาชิก/ศูนย์ และค้นหาองค์กรสมาชิกจากช่องค้นหากลาง
- หน้าแรกแสดงช่องเนื้อหาโครงการ ข่าว รายงาน และสถานะว่างเมื่อไม่มี published; หน้าสื่อรวมภาพจากข่าว/โครงการ published; หน้าเนื้อหารายละเอียดแสดงรายการในหมวดหรือฝ่ายเดียวกันเมื่อมี
- คงการรับเงินและฟอร์มส่งเอกสารสมาชิกปิดไว้ตามขอบเขตที่ยืนยัน ข้อมูลจำลองใน Supabase ยังเป็น draft และไม่ขึ้นเว็บสาธารณะ

ข้อที่ยังไม่ปิด: ผัง/ชื่อผู้บริหารและสมาชิกสภา, รายชื่อศูนย์จังหวัด, บทบาทฝ่ายกิจการพิเศษ, รายการข่าว/โครงการ/รายงานและสื่อจริงที่ผ่านอนุมัติ, ตัวเลขผลลัพธ์/งบ, กฎคำนวณซะกาต, ประเภทสมาชิก/เอกสาร/นโยบายส่วนบุคคล, ประเภทข่าววิชาการ/วิดีโอใน CMS, workflow หลาย role, emergency banner, canonical/OG/sitemap/redirect (รอ domain และ URL เดิม) และการวัด performance/analytics สำหรับ production. อย่าใช้ตารางเดิมด้านล่างเป็นสถานะล่าสุดโดยไม่อ่านสรุปนี้

## 4–5. เกี่ยวกับเราและโครงสร้างบริหาร

- `/about` มีคำอธิบายองค์กรแบบสั้นและลิงก์ไปหน้าที่เกี่ยวข้อง แต่ยังไม่ใช่ข้อความแนะนำเต็ม 250–400 คำหรือสารจากประธาน
- `/about/history` มีโครง timeline แต่ยังไม่ใส่เหตุการณ์; เอกสารให้วันก่อตั้งในภาษาไทยปี 2557 ขณะที่ข้อความอังกฤษกล่าวปี 2015 จึงต้องให้เจ้าของข้อมูลยืนยันก่อนลงหน้าเว็บ
- `/about/direction` มีหัวข้อวิสัยทัศน์ พันธกิจ วัตถุประสงค์ และยุทธศาสตร์ แต่ยังไม่มีข้อความทางการหรือกรอบยุทธศาสตร์ 6 ด้านที่เผยแพร่
- `/about/structure` มีแผนผังระดับสูงและรายชื่อ 8 ฝ่าย แต่ยังไม่มีผังองค์กรฉบับจริง รายชื่อกรรมการ/ผู้บริหาร รูป และข้อมูลสมาชิกสภา
- ภาพสำนักงาน/ภารกิจ/เครือข่าย และสารประธานในเอกสารยังเป็นช่องเตรียมข้อมูล จึงยังไม่สามารถถือว่าพร้อมเผยแพร่

## 9–10. โครงการ ข่าว และรายงาน

| ส่วน | สิ่งที่ทำแล้ว | สิ่งที่ยังขาดจาก brief |
| --- | --- | --- |
| โครงการ | มี CMS สร้าง/แก้/ร่าง/เผยแพร่, ภาพพร้อม alt/เครดิต/ยืนยันสิทธิ์, หน้า card/detail และการเชื่อมฝ่าย | ไม่มีตัวกรองหน้าโครงการ; โมเดลไม่มีระยะเวลา ผู้รับประโยชน์ เป้าหมาย งบ ผลลัพธ์ วันที่อัปเดต ภาคี หลักฐาน/แกลเลอรี และยอดสนับสนุน; ยังไม่มีโครงการ published |
| ข่าว/บทความ | มี CMS ชนิด `news`/`story`, ภาพ, หน้า list/detail และการกรองผ่าน query `kind` | ไม่มีหมวดวิชาการ/วิดีโอ, วันกิจกรรม, ฝ่าย/พื้นที่, Project ID, tag, ผู้เขียน, rich media/caption, share หรือ related content; ยังไม่มีข่าว published |
| รายงาน | มี CMS อัปโหลด PDF พร้อมเจ้าของข้อมูลและสิทธิ์, หน้า list/detail และดาวน์โหลดเมื่อ published | ไม่มีไฟล์ published, ยังไม่ผูกโครงการ/ฝ่าย, ไม่มีการกรองปี/หมวดหรือปกเอกสาร |

ตัวอย่างโครงการ “LIFE MUST go on” ในเอกสารมีคำอธิบาย แต่ช่องเป้าหมายเชิงปริมาณ งบ ผลลัพธ์และช่วงเวลาดำเนินงานยังว่าง รวมทั้งมีหัวข้อ “8.2 ศูนย์ประสานงานระดับจังหวัด” ปะปนอยู่ในบล็อกโครงการ จึงต้องตรวจต้นฉบับก่อนใช้เป็นข้อมูลโครงการจริง

## 11–13. ร่วมสนับสนุน สมัครสมาชิก ติดต่อ

- `/participate` และ `/participate/donate` อธิบายขั้นตอน แต่ไม่มีการเลือกยอด ชำระเงิน แนบหลักฐาน ใบเสร็จ เลขอ้างอิง หรือการติดตามผล; ไม่มีบัญชี/QR บนเว็บ
- `/participate/membership` อธิบายขั้นตอน แต่ไม่มีฟอร์ม ประเภทสมาชิก ไฟล์แนบ checkbox PDPA เลขอ้างอิง หรือระบบรับเรื่องแบบจำกัดสิทธิ์
- `/contact` ยังเป็น placeholder ไม่มีข้อมูลกลางและไม่มีฟอร์ม แม้เอกสารส่งที่อยู่ เบอร์ อีเมล เวลาทำการ social และแผนที่มาเป็น **ข้อมูลตั้งต้น**; เอกสารเองระบุความไม่ตรงกันของข้อมูลเว็บเดิม จึงควรยืนยันชุดข้อมูลทางการก่อนเผยแพร่

| Breadcrumb | ยังไม่มี component หรือเส้นทางย้อนกลับแบบ breadcrumb ในหน้าใน |
| Share | ยังไม่มี Facebook / LINE / Copy link บนข่าวและโครงการ |
| Related content | หน้าแต่ละฝ่ายเชื่อมโครงการ published ได้; ข่าว/โครงการที่เกี่ยวข้องผ่าน tag/CMS ยังไม่มี |
| Footer | มี quick links, privacy/cookies link และปี dynamic; ไม่มีข้อมูลติดต่อหรือ social ที่ยืนยัน |
| TH/EN | เว็บภาษาไทยเท่านั้น ยังไม่มี locale structure ที่ใช้งาน |
| Emergency banner | ยังไม่มี CMS เปิด/ปิดและกำหนดช่วงเวลา |

การค้นหายัง **ไม่รวมองค์กรสมาชิก** แม้ brief ระบุไว้ และยังไม่มี filter/หน้าแยกผลตามชนิด

## 15–16. เกณฑ์พัฒนาและความพร้อมใช้งานจริง

| หัวข้อ | ผลตรวจ |
| --- | --- |
| Responsive / Accessibility | มี CSS desktop/mobile, focus styles, alt ของรูปใน CMS; ยังไม่ใช่ผล audit WCAG ครบทุกหน้า/ฟอร์ม และยังไม่มีฟอร์มบริจาค/สมัครให้ทดสอบ |
| CMS / สิทธิ์ | Supabase Auth, RLS, private storage และ admin สำหรับ Hero, ข่าว, โครงการ, รายงาน, โลโก้ภาคี, เนื้อหาเด่นมีแล้ว; ยังไม่มี CMS ฝ่าย/ศูนย์/สื่อ/settings และ workflow editor→reviewer→publisher/revision |
| SEO | มี title/description บางหน้าและ dynamic metadata ของ detail; root ตั้ง `noindex`; ยังไม่มี canonical, Open Graph image, sitemap, redirect 301 ที่ตรวจได้ และยังไม่พร้อมเปิด index |
| Performance | ใช้ Next Image และแปลงภาพอัปโหลดบางชนิด; ยังไม่มีผลวัด Core Web Vitals/งบขนาดภาพทั้งไซต์ |
| PDPA / Cookies | หน้านโยบายยังเป็น placeholder; ไม่มี consent manager หรือ retention workflow; ควรกำหนดตามระบบจริงก่อนเปิดฟอร์มหรือ analytics |
| Security | ระบบ admin ที่มีอยู่ตรวจสิทธิ์ server/data access และ RLS; ระบบรับสมัคร/ไฟล์ส่วนบุคคล, anti-spam/CAPTCHA และสแกนมัลแวร์ยังไม่มีเพราะยังไม่เปิดฟอร์ม |
| Analytics | ยังไม่มี GA4 หรือ event CTA/Donate/Form/Download/Search |
| Backup / Staging | มีสคริปต์ backup ในเครื่อง; ยังไม่เห็นรอบสำรองอัตโนมัติ, การกู้คืนที่ทดสอบแล้ว, ผู้รับผิดชอบ หรือ staging/deploy process ในโค้ด |

## ลำดับที่ควรทำต่อ

1. **ยืนยันข้อมูลทางการและความปลอดภัยของเนื้อหา:** ประวัติที่ปีไม่ตรง, ข้อความวิสัยทัศน์/พันธกิจ, ผัง/รายชื่อบริหาร, ชื่อภาคี, ข้อมูลติดต่อ, สิทธิ์ภาพ และรายการที่จะเผยแพร่จริง
2. **เติมหน้าแกนหลัก:** ข้อมูลเฉพาะ 8 ฝ่าย, ศูนย์ภูมิภาคที่ยืนยันแล้ว, อย่างน้อยโครงการ/ข่าว/รายงานที่ approved; เพิ่ม field โครงการและข่าวให้รองรับ brief ก่อนนำเข้าจำนวนมาก
3. **ทำเส้นทางผู้ใช้ที่ยังขาด:** ตัวกรองโครงการ/ข่าว, share, related content, breadcrumb, search สมาชิก, ซะกาต calculator; ออกแบบ flow สนับสนุนและสมัครสมาชิกตามข้อกำหนดที่รับรองแล้ว
4. **เตรียมเปิดใช้งานจริง:** privacy notice, SEO/redirect/sitemap, analytics, workflow อนุมัติ, backup/restore และ staging
