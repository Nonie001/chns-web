# ภาพและข้อมูล mockup

สถานะ: นำเข้า Supabase เป็นฉบับร่างสำหรับพรีวิวหลังบ้านเท่านั้น ไม่ใช่ภาพการดำเนินงานหรือข่าวจริงของ CHNS

## ภาพ

สร้างด้วยเครื่องมือ ImageGen ในโปรเจกต์นี้ แล้วแปลงเป็น JPEG เพื่อลดขนาดไฟล์ ภาพทุกภาพเป็นฉากสมมติ ไม่มีโลโก้หรือบุคคลที่ระบุตัวได้ ไฟล์ต้นฉบับอยู่ใน `assets/mockups/` และไฟล์สำหรับพรีวิวอยู่ใน private Supabase Storage ไม่อยู่ใน `public/`

| ไฟล์ | คำอธิบาย prompt ที่ใช้ | ใช้ในหน้า |
| --- | --- | --- |
| `assets/mockups/community-relief.jpg` | อาสาสมัครสมมติในเอเชียตะวันออกเฉียงใต้ขนกล่องช่วยเหลือและน้ำ มุมด้านหลัง แสงอบอุ่น ไม่มีโลโก้ ข้อความ หรือใบหน้าชัด | ร่างโครงการ ข่าว และ Hero |
| `assets/mockups/food-packing.jpg` | อาสาสมัครสมมติจัดชุดอาหารในศูนย์ชุมชนไทย ไม่มีโลโก้ ข้อความ หรือใบหน้าชัด | ร่างโครงการ ข่าว และ Hero |
| `assets/mockups/coordination.jpg` | มือผู้ประสานงานสมมติพิจารณาแผนที่และสมุดบันทึกในสำนักงานเอเชียตะวันออกเฉียงใต้ ไม่มีโลโก้ ข้อความ หรือใบหน้าชัด | ร่างโครงการและ Hero |

ข้อมูลตัวอย่าง 3 สไลด์ 6 โครงการ 11 ข่าว/บทความ และ 3 รายงานอยู่ใน Supabase โดยมี `is_mockup=true`, `status='draft'` และกฎฐานข้อมูลห้ามเปลี่ยนเป็น published ข่าว/บทความ 11 รายการและโครงการ 6 รายการตั้ง `showcase_visible=true` ตามคำขอให้เห็นบนหน้าเว็บ พร้อมป้ายตัวอย่าง ก่อนเผยแพร่เนื้อหาจริงต้องสร้างรายการใหม่ที่ผ่าน workflow อนุมัติ พร้อมตรวจสิทธิ์ภาพ คำบรรยาย แหล่งข้อมูล วันที่ และความสัมพันธ์กับฝ่าย/โครงการ
