## User Flow

- ผู้สนับสนุน: เข้าโครงการและหน้าร่วมสนับสนุนได้ แต่ยังไม่มีธุรกรรมหรือการยืนยัน/ติดตามผล
- ประชาชน: เข้าโครงการ ข่าว และสื่อได้เมื่อมีข้อมูล published; ภาพ/ผลลัพธ์และปุ่มแชร์ยังไม่ครบ
- สื่อ/นักวิชาการ: ค้นหาและดาวน์โหลดรายงานที่ published ได้; ยังไม่มีไฟล์เผยแพร่จริงและข้อมูลติดต่อฝ่ายที่ยืนยันแล้ว
- ผู้สมัครสมาชิก: อ่านขั้นตอนได้ แต่ยังไม่มีแบบฟอร์ม เอกสารแนบ PDPA และการส่งเรื่อง

## Mapping จากเว็บเดิม

URL เดิมและ domain ยังไม่อยู่ในข้อมูลโปรเจกต์ จึงยังตรวจการคง URL หรือสร้าง 301 Redirect ไม่ได้ โดยเฉพาะฝ่ายช่วยเหลือผู้ยากไร้และชื่อฝ่ายซะกาตเดิม ต้องได้ URL inventory จากเจ้าของเว็บก่อนแก้ redirect. โครงหน้าใหม่สำหรับฝ่ายวิชาการ องค์กรสัมพันธ์ กิจการพิเศษ การตลาดและสื่อสาร ศูนย์ และองค์กรสมาชิกมีแล้ว แต่ยังรอเนื้อหาที่อนุมัติ
