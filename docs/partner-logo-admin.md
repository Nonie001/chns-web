# โลโก้ภาคีเครือข่าย

สถานะ 25 กันยายน 2569: หน้าแรก `/`, หน้าภาคี `/members` และหลังบ้าน `/admin/partners` ใช้รายการภาคีเดียวกันแล้ว โลโก้แสดง **ทีละภาพ** บนพื้นขาวเรียงเป็นตารางไร้กรอบ ทั้งหน้าแรกและหน้าภาคีแสดงครบ 47 ภาพที่เผยแพร่ทันที โดยไม่ต้องกดดูทั้งหมดและไม่ลิงก์จากตัวโลโก้ ภาพรวมโลโก้แนวนอนถูกนำออกแล้ว

## ภาพเริ่มต้นจาก CHNS Drive

- นำเข้าไฟล์ `IMG_*.JPG/PNG` 47 ไฟล์จาก [โฟลเดอร์โลโก้ภาคี](https://drive.google.com/drive/folders/1goAC-YlKr0EbXCsbWcrWtrvedmLuo9G1?usp=drive_link) หลังผู้ใช้ยืนยันว่าได้รับอนุญาตให้เผยแพร่ครบแล้ว ไม่ได้นำภาพรวม 2 ไฟล์มาแสดง
- ตัดแถบดำจากภาพหน้าจอ 2 ไฟล์ (`IMG_0599.PNG`, `IMG_0611.PNG`) และตัดขอบว่างของภาพอื่น แล้วแปลงเป็น WebP กว้างไม่เกิน 420 px สูงไม่เกิน 320 px คุณภาพ 82: รวม **11.81 MB → 0.65 MB** (47 ภาพ)
- ไฟล์ที่ปรับแล้วอยู่ใน `assets/partner-logos/` พร้อม `manifest.json` เพื่อเก็บต้นฉบับใน repository; 47 รายการและภาพถูกนำเข้า Supabase แล้ว และเสิร์ฟผ่าน `/api/partner-logos/[key]`
- ชื่อไฟล์ต้นฉบับเป็น `IMG_...` และไม่ได้ระบุชื่อองค์กรเป็น metadata จึงให้รายการเริ่มต้นใช้ชื่ออ้างอิงไฟล์ในหลังบ้าน เช่น `ภาคี IMG_0574` โดย **ไม่แสดงชื่อชั่วคราวบนหน้าเว็บ** ผู้ดูแลควรแก้ชื่อและ alt ให้ตรงองค์กรหลังตรวจจากเจ้าของข้อมูล รูปจริงถูกเผยแพร่ตามการยืนยันสิทธิ์ของผู้ใช้
- รายการเริ่มต้นตรวจด้วย ID คงที่จากชื่อไฟล์ เมื่อแก้ชื่อ/สถานะ/ลำดับในหลังบ้านแล้ว การเริ่มระบบใหม่จะไม่ทับการแก้ไขนั้น

## วิธีเพิ่มรายการ

1. เข้าหลังบ้าน > โลโก้ภาคี > เพิ่มภาคี
2. กรอกชื่อองค์กรตามที่เจ้าของข้อมูลยืนยัน เว็บไซต์ (ถ้ามี) และอัปโหลดภาพ JPG/PNG/WebP ขนาดไม่เกิน 5 MB อย่างน้อย 200 × 100 px
3. ใส่คำอธิบายโลโก้สำหรับการเข้าถึงและที่มา/เครดิตไฟล์ แล้วติ๊กยืนยันสิทธิ์เผยแพร่
4. บันทึกเป็นร่าง ตรวจรูปและชื่อบนหน้ารายการ จากนั้นกดเผยแพร่ จัดลำดับด้วยปุ่มขึ้น/ลง หรือปิดเผยแพร่/เก็บถาวรได้

หาก CHNS ส่งไฟล์ชุดใหม่ ให้แตก ZIP ในโฟลเดอร์ชั่วคราวแล้วรัน `node scripts/optimize-partner-logos.mjs /path/to/extracted-files` จากรากโปรเจกต์ ตรวจ `manifest.json` และภาพจริง จากนั้นเพิ่มรายการผ่านหลังบ้านก่อนเผยแพร่

## สัญญาข้อมูลและความปลอดภัย

- ตาราง Supabase `partners` เก็บชื่อ เว็บไซต์ คีย์โลโก้ คำอธิบาย เครดิต การยืนยันสิทธิ์ สถานะ ลำดับ และเวลาที่เผยแพร่; `partner_audit` เก็บผู้ทำและการเปลี่ยนแปลง
- รูปอยู่ใน private Supabase Storage และแปลงเป็น WebP โดยรักษาพื้นหลังโปร่งใส Route `/api/partner-logos/[key]` คืนรูปเฉพาะรายการ published + rights confirmed หรือผู้ดูแลที่ล็อกอิน
- การแก้และสถานะเรียก Server Actions ที่ตรวจสิทธิ์ admin ซ้ำทุกครั้ง ทั้ง data access และการเปลี่ยนลำดับตรวจ session อีกชั้น
- หลังบ้านยังเก็บ URL `http`/`https` ของภาคีได้ แต่หน้าแสดงโลโก้ปัจจุบันไม่ทำให้ภาพเป็นลิงก์ตามคำขอผู้ใช้
- `npm run backup:local -- --out ...` ใช้สำรองข้อมูล SQLite เดิม; SQL/RLS สำหรับระบบปัจจุบันอยู่ใน `supabase/migrations/`

ยังไม่มีระบบสมัครสมาชิกองค์กรหรือการเชื่อมภาคีกับโครงการ; งานเหล่านี้พักตามขอบเขตที่ผู้ใช้กำหนด
