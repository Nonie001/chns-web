# เนื้อหาเด่นหน้าแรก

สถานะ: ใช้งานในเครื่องได้สำหรับข่าว/บทความเด่นหนึ่งรายการและโครงการหน้าแรกสิบช่อง

ผู้ดูแล `admin` เปิด `/admin/homepage/features` เพื่อลากโครงการที่เผยแพร่ลงตัวอย่างหน้าแรก หรือเลือกช่องแล้วคลิกโครงการ มีตัวเลือกแบบ select สำหรับมือถือและคีย์บอร์ด ก่อนกดบันทึกจะเห็นตัวอย่างทันที ช่อง `project_1` คือภาพใหญ่, `project_2`–`project_5` คือการ์ดขวา และ `project_6`–`project_10` คือแถวล่าง เลือกโครงการเดียวกันซ้ำได้สำหรับการนำเสนอ เมื่อโครงการเพิ่มขึ้น กด “ล้างช่องที่ซ้ำ” แล้วบันทึกเพื่อลบการเลือกซ้ำ โดยไม่ลบตัวโครงการ หากปล่อยช่องว่างหรือรายการที่เลือกถูกปิดเผยแพร่ หน้าแรกจะใช้โครงการเผยแพร่อื่นเติมตามลำดับเมื่อมีรายการเพียงพอ โดยไม่แสดงร่าง

ค่าที่เลือกเก็บใน `homepage_features` โดยอ้างอิง `content_id`; การแก้ไขเก็บผู้ทำ เวลา และค่าก่อน/หลังใน `homepage_feature_audit` Server Action ตรวจ session/role และตรวจสถานะเนื้อหาที่ server ก่อนบันทึก หน้าเว็บตรวจสถานะอีกครั้งขณะอ่าน

ขอบเขตปัจจุบันมีเฉพาะการเลือกข่าวและโครงการ ไม่รวมแบนเนอร์เร่งด่วน ตารางเวลาเริ่ม/สิ้นสุด หรือการอนุมัติหลายระดับ โมดูลสไลด์ Hero จัดการแยกที่ `/admin/homepage/slides`

ทดสอบบนฐานข้อมูลชั่วคราว: เลือกโครงการเด่นที่เก่ากว่าโครงการอื่น หน้าแรกแสดงรายการที่เลือกก่อน; ปิดเผยแพร่รายการที่เลือกแล้วหน้าแรกไม่แสดงร่างและแสดงโครงการเผยแพร่อื่นแทน
