# ข่าวและบทความ: โมดูลหลังบ้านเฟส 2

สถานะ: ใช้งานในเครื่องได้สำหรับผู้ดูแล `admin`; เป็นโมดูลคอนเทนต์แรกของเฟส 2 ยังไม่ถือว่าเฟส 2 ทั้งหมดเสร็จ

## การใช้งาน

1. เข้าสู่ระบบที่ `/admin/login` แล้วเปิด `/admin/articles`
2. เพิ่มข่าวหรือบทความ ระบุ URL slug ภาษาอังกฤษพิมพ์เล็ก หัวเรื่อง สรุป และเนื้อหาแบบข้อความธรรมดา ใช้บรรทัดว่างคั่นย่อหน้า
3. หากอัปโหลดภาพปก ต้องระบุคำอธิบายภาพ เครดิต/ที่มา และยืนยันสิทธิ์เผยแพร่ ระบบตรวจไฟล์ JPG/PNG/WebP ไม่เกิน 5 MB และกว้างอย่างน้อย 800 px ก่อนแปลงเป็น WebP
4. บันทึกเป็นร่าง เปิดพรีวิวที่ `/admin/articles/[id]/preview` แล้วกดเผยแพร่จากหน้ารายการเมื่อข้อมูลผ่านการตรวจ หลังเผยแพร่จะแสดงที่ `/news/[slug]`, หน้ารวมข่าว, หน้าแรก และผลค้นหา
5. ปิดเผยแพร่หรือเก็บถาวรจากหน้ารายการได้ทันที หน้าสาธารณะและภาพปกจะไม่แสดงรายการนั้น

## การแยกข้อมูลร่างกับข้อมูลสาธารณะ

- ตาราง `articles` เก็บเนื้อหาและสถานะ; `article_audit` เก็บผู้ทำ เวลา และค่าก่อน/หลังทุกครั้งที่สร้าง แก้ หรือเปลี่ยนสถานะ
- public query เลือกเฉพาะ `published`; query หลังบ้านตรวจ session และ role `admin` ทุกครั้ง
- Server Actions ตรวจสิทธิ์และข้อมูลซ้ำที่ server; media route ตอบ 404 สำหรับภาพของร่าง/รายการปิดเผยแพร่เมื่อไม่ได้ล็อกอิน
- ข่าวและบทความตัวอย่างเดิมถูกลบจากฐานข้อมูลและ Storage แล้ว ไม่มี fallback แสดงข้อมูลร่างบนหน้าสาธารณะ
- การแก้ข่าวที่เผยแพร่มีผลทันทีและถูกบันทึก audit; ยังไม่มี workflow แก้เป็น revision แยกก่อนอนุมัติ

## ที่เก็บและการสำรองข้อมูล

- ข้อมูลอยู่ใน Supabase PostgreSQL; ภาพปกอยู่ใน private Storage ไม่อยู่ใน `public/`
- ต้องจัดแผนสำรองฐานข้อมูลและ Storage พร้อมทดสอบ restore ก่อนใช้จริง

## ขอบเขตที่ยังต้องทำเพื่อจบเฟส 2

- เพิ่ม role/scope ของ editor, reviewer, publisher และ revision ที่แก้ข่าวเผยแพร่แล้วโดยไม่เปลี่ยนหน้าสาธารณะทันที
- โมดูลโครงการ รายงาน PDF และการเลือกเนื้อหาเด่นหน้าแรกมีหลังบ้านแยกแล้ว; คลังสื่อร่วมยังเป็นแผน
- ขั้นตอนอนุมัติสิทธิ์ภาพหลายคน, backup/restore อัตโนมัติ และการทดสอบสิทธิ์ครบทุก role ยังไม่พร้อมสำหรับ production

## การตรวจรอบนี้

- ทดสอบบนฐานข้อมูลชั่วคราวแยกจากข้อมูลผู้ใช้: ร่างตอบ 404 บน public, ภาพร่างตอบ 404, ผู้ไม่ล็อกอินถูกส่งไปหน้า login
- ใช้บัญชีทดสอบชั่วคราวสร้างร่างผ่านฟอร์มจริง พรีวิว เผยแพร่ พบที่หน้ารวม/รายละเอียด/ค้นหา แล้วปิดเผยแพร่และยืนยันว่า public กลับเป็น 404
