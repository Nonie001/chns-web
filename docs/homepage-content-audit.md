# ตรวจหน้าแรกเทียบ Content Wireframe ข้อ 3.1–3.6

ตรวจวันที่ 25 กันยายน 2569 จาก `src/app/(site)/page.tsx`, โมเดลข้อมูล, หน้าเว็บในเครื่อง และฐานข้อมูล `.data/chns.sqlite` แบบอ่านอย่างเดียว

**ผลรวม: ยังไม่ครบตาม wireframe** โครงหน้ามี Hero, การ์ดโครงการ/ข่าว, ฝ่ายงาน 8 ฝ่าย และส่วนชวนร่วมสนับสนุน แต่ Supabase ยังไม่มี Hero/ข่าว/โครงการ/รายงานจริงที่เผยแพร่ ตัวอย่างทั้งหมดเป็น draft สำหรับพรีวิวหลังบ้าน หน้าแรกจึงแสดงเฉพาะข้อมูลสาธารณะที่ได้รับอนุมัติและส่วนจัดวางที่ไม่อ้างเหตุการณ์จริง

| ข้อ | สถานะปัจจุบัน | สิ่งที่ยังขาดเมื่อเทียบแบบ |

| 3.1 Hero Banner | มีสไลด์ภาพเลื่อนวนทุก 6 วินาที ปัด/เลือกภาพได้ และจัดการภาพผ่าน admin; preview ใช้ภาพจำลอง 3 ภาพ | ยังไม่มีภาพจริงที่เผยแพร่; ระบบไม่จำกัดสไลด์จริงไว้ที่ 3; ยังไม่ตรวจขนาด/สิทธิ์ภาพจาก Drive; ไม่มี Headline, Subheadline, CTA บน Hero ตามคำขอเดิมของผู้ใช้ให้เป็น **ภาพล้วน** |
| 3.2 โครงการเร่งด่วน | หน้าแรกมี 2 โครงการเด่นจากรายการ published หรือ mockup และกดไปหน้ารายละเอียดได้ | ยังไม่ใช่ส่วนโครงการเร่งด่วน 3–6 รายการ; การ์ดไม่มีพื้นที่ เป้าหมาย สถานะภารกิจ; โมเดลยังไม่มีเป้าหมาย/ความเร่งด่วน/ผลลัพธ์; ไม่มี progress การบริจาค เพราะระบบบริจาคพักไว้ |

| 3.5 เรื่องราวจากพื้นที่ | โมเดลบทความมี `kind=story` และตรวจสิทธิ์เผยแพร่ภาพทั่วไป | ยังไม่มีส่วนเรื่องราวจากพื้นที่บนหน้าแรกหรือรายการที่เลือกเฉพาะ story; ยังไม่มีหลักฐานการอนุญาตภาพบุคคล/ข้อมูลเรื่องเล่า |
| 3.6 ภาคีเครือข่าย | มีส่วนโลโก้รายภาพบนหน้าแรกและ `/members` แสดงครบ 47 ภาพแบบตารางไร้กรอบ ไม่ต้องกดดูทั้งหมด ดึงรายการ published จาก CMS `/admin/partners`; แปลงเป็น WebP ขนาดเล็กแล้ว | ชื่อองค์กรรายไฟล์ยังต้องตรวจและแก้ในหลังบ้าน เพราะต้นทางใช้ชื่อ `IMG_...`; หน้าเว็บแสดงเฉพาะภาพจึงไม่อ้างชื่อองค์กรที่ยังไม่ตรวจ |

## ไฟล์ที่ CHNS ส่งเป็นลิงก์

- [ภาพ Hero](https://drive.google.com/drive/folders/1nd6G8L1erKGjOXBZiszvi8bFh0RisQJb?usp=sharing): เปิดได้ พบภาพ 4 ไฟล์ในโฟลเดอร์ `cover` แต่ยังไม่ได้ตรวจความละเอียด อัตราส่วน ข้อความในภาพ และสิทธิ์เผยแพร่ ไม่ได้เชื่อมเข้า admin
- [ภาพภารกิจล่าสุด](https://drive.google.com/drive/folders/1zIXiWdzWLGUNljP7FiBOs_AAETaNHxFD?usp=drive_link): บัญชีที่ใช้ตรวจได้รับหน้าขอสิทธิ์เข้าถึง จึงยังยืนยันรายการภาพไม่ได้
- [โลโก้องค์กรเครือข่าย](https://drive.google.com/drive/folders/1goAC-YlKr0EbXCsbWcrWtrvedmLuo9G1?usp=drive_link): ผู้ใช้ยืนยันสิทธิ์เผยแพร่ นำเข้า 47 ภาพรายองค์กรพร้อมที่มาระดับไฟล์แล้ว; ชื่อทางการแต่ละองค์กรยังต้องตรวจในหลังบ้าน

โลโก้ชุดนี้นำเข้าตามคำขอผู้ใช้แล้ว การเพิ่มภาพชุดใหม่ยังต้องตรวจข้อมูลก่อนเผยแพร่

## ลำดับงานที่แนะนำ

1. ยืนยันรูปแบบ Hero ตามคำขอเดิม: ภาพล้วนไม่ซ้อนข้อความ ถ้าต้องมี CTA ที่กดได้ ให้กำหนดลิงก์รายภาพหรือวางปุ่มนอกตัวภาพโดยเจ้าของงานยืนยันก่อน
2. เพิ่มข้อมูลโครงการที่หน้าแรกต้องใช้ (`isUrgent`/ลำดับ, เป้าหมาย, สถานะ, พื้นที่) แล้วแสดง 3–6 รายการ published โดยไม่ใช้ตัวเลขหรือ progress ที่ไม่มีหลักฐาน
3. เพิ่มฝ่าย/พื้นที่/วันที่ในข่าวและทำส่วนข่าวล่าสุด 6 เรื่องอัตโนมัติ; ทำส่วน story แยกเมื่อมีเนื้อหาและสิทธิ์ภาพบุคคล
4. เติมคำอธิบายและภาพ/ไอคอนของ 8 ฝ่ายหลังเจ้าของข้อมูลตรวจ; เพิ่มข้อมูลภาคีและสิทธิ์โลโก้ก่อนแสดงบนหน้าแรก
5. นำภาพจริงเข้า admin หลังตรวจขนาด/สิทธิ์ และปิด mockup ก่อนเผยแพร่เว็บจริง

ระบบสมัครสมาชิก บริจาค และภาษาอังกฤษยังพักไว้ตามขอบเขตที่ผู้ใช้กำหนด
